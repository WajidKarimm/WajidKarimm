##  Featured Projects

### 🩺 ASA-Agent: Multi-Agent Healthcare Assistant
Multi-agent healthcare assistant where specialist agents handle separate parts of a request and a coordinating agent routes work between them. Demonstrates how multi-agent systems stay reliable when a single prompt is not enough.
`LangGraph` `LangChain` `Python` `Multi-Agent Systems`

### 🧭 Multi-Agent Supervisor System (FastAPI + Groq)
Supervisor-based architecture where a Groq-powered LLM routes tasks to specialist agents through a FastAPI backend. Covers task routing, agent handoffs, and tool calling. A reusable foundation for client AI automation.
`FastAPI` `Groq` `Python` `AI Automation`

### 🌐 AI Browser Assistant (Playwright MCP)
An agent that controls a real browser via Playwright and MCP, executing web tasks on command. A React front end lets users watch and direct the agent, backed by FastAPI and tool-calling agents.
`MCP` `Playwright` `FastAPI` `React`

### 📄 RAG Document Q&A on pgvector
Pipeline that answers questions from your own documents: chunking, embedding into pgvector on PostgreSQL, retrieval, and grounded LLM answers. Includes testing for empty and weak retrievals.
`RAG` `LangChain` `PostgreSQL` `pgvector`

### 🏔️ AI Tools for Burushaski & Shina Language Preservation
NLP and speech recognition work supporting two endangered languages of Gilgit-Baltistan. Tackles low-resource data where standard models have little coverage, including annotation and ASR.
`NLP` `Speech Recognition` `Data Annotation` `Machine Learning`
